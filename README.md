# AI R&D Lab

An open-source research and development laboratory focused on exploring modern Artificial Intelligence technologies through hands-on experimentation.

## 🎯 Objective

The goal of this laboratory is to understand how modern AI systems work by building progressively more complex experiments from the ground up.

Rather than simply using AI APIs, the project focuses on understanding the technologies behind AI-powered applications, including:

* Local Large Language Models
* Tool Calling
* Model Context Protocol (MCP)
* Retrieval-Augmented Generation (RAG)
* AI-powered Data Analytics
* SQL Agents
* AI Agent Architectures
* Multi-Agent Systems
* AI Automation

## 🧪 Research Approach

Each experiment is designed as an independent technical investigation.

For every experiment we document:

* What we are building
* Why the technology is relevant
* How it works
* Implementation
* Results
* Limitations
* Lessons learned
* Possible real-world applications

The objective is to move from simple experiments to increasingly autonomous AI systems.
